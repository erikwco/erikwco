## 🏗️ What I'm Building — Gibbor

<table>
<tr>
<td width="60%">

**Gibbor** *(גִּבּוֹר — "mighty")* is a **multi-tenant SaaS ERP** built for Central American SMBs, **in production**:

- 🧾 **FEL/DTE e-invoicing** — CCF, FCF, exportación, retención, sujeto excluido & invalidación with JWS signing
- 🔐 **Multi-tenancy with PostgreSQL Row-Level Security**
- ⚡ **React Router v8 SSR** frontend + **Go** signing microservice + **Quarkus** & **.NET 8** services
- 📨 **NATS** messaging · **Valkey** caching · **PgBouncer** pooling
- 🛡️ Self-hosted on dedicated hardware: **Docker Compose + Traefik + CrowdSec**, secrets with **SOPS+age**, backups with **Restic + B2**
